# E-Store - Online Electronics Shop UI

A clean and modern **eCommerce website UI** for electronic products built with **HTML, CSS, and Bootstrap**.

This project is a **static front-end design** showcasing a professional online electronics store — featuring product listings, product details, cart, and checkout pages.

---

## 🚀 Features
- Fully responsive layout using Bootstrap 5
- Modern and minimal design
- Product grid & product details section
- Shopping cart and checkout pages
- Contact and About sections
- Breadcrumb navigation and filter options

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **Bootstrap 5**

---

## 📄 Pages
- `index.html` — Home page  
- `about.html` — About Us page  
- `contact.html` — Contact Form  
- `products.html` — Product Listing page  
- `product-details.html` — Product Details  
- `cart.html` — Shopping Cart  
- `checkout.html` — Checkout page
